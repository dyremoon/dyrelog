A behind-the-scenes release: a newer, safer engine and a few small improvements.

**What's new**
- Dyrelog now runs on a current version of Electron (the engine it's built on), with up-to-date security fixes.
- EverQuest submit sounds now play straight from your own EverQuest folder instead of being bundled with Dyrelog. Your chosen sound keeps working.
- The fonts in Settings → Font are built in, so the Rounded and Monospace options finally look the way they should, and Dyrelog no longer downloads fonts when it starts.
- On the website you can now **Log out everywhere** from your profile, which logs you out of the desktop app and every browser at once.

**Fixes and polish**
- Removed submit sounds Dyrelog didn't have the rights to share. If you had one of them selected, it's switched to "No sound"; you can pick another or use your own MP3.
- "Upload MP3" is now "Use my own MP3…", and the leaderboard window's column headings all match.
- Extra protection so the app's windows can only run Dyrelog's own code.

### How to install and update

**Already have Dyrelog 0.1.17 or newer?** You don't need to download anything. Dyrelog shows an update banner at the top of the meter within about an hour (or right away when you start it). Click it and Dyrelog downloads the update, installs it and restarts. You can also check any time in **Settings → What's New → Check for updates**.

**New install, or on 0.1.16 or older?**
1. Download **Dyrelog-Setup-0.1.19.exe** below. (Ignore the `.blockmap` and `latest.yml` files; those are for the updater.)
2. Run it. If Windows SmartScreen warns you, choose **More info**, then **Run anyway**.
3. Open Dyrelog and pick your EverQuest folder. In game, type `/log on` if you haven't before.

Windows 10 or 11 only.
