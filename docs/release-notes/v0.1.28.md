The meter stays on top of EverQuest, and kill submission is more reliable when Dyrelog's server is busy.

**Fixes**
- The meter no longer sometimes ends up behind EverQuest when you click back into the game (most often in borderless fullscreen).
- A kill that was being submitted when the server hit a limit is now finished automatically later, instead of sometimes being dropped as "already submitted".
- Hitting a server limit no longer logs you out of Dyrelog.
- If the server is at its daily limit when you log in, Dyrelog says so instead of "Couldn't log in".
- Dyrelog recognizes more kinds of "server is at its limit" answers, so saved kills wait and retry instead of showing an error.

### How to install and update

**Already have Dyrelog 0.1.17 or newer?** You don't need to download anything. Dyrelog shows an update prompt within about an hour (or right away when you start it). Click it to install, or check any time in **Settings → What's New → Check for updates**.

**New install?**
1. Download **Dyrelog-Setup-0.1.28.exe** below. (Ignore the `.blockmap` and `latest.yml` files; those are for the updater.)
2. Run it. If Windows shows "Windows protected your PC", choose **More info**, then **Run anyway**. That warning is normal for small apps without a paid code-signing certificate.
3. Open Dyrelog and pick your EverQuest folder. In game, type `/log on` if you haven't before.

Windows 10 or 11 only.
