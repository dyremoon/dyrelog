Setup

1. Turn on logging in-game

Type /log on in your chat window, or set Log=TRUE permanently in eqclient.ini. EverQuest then writes every line you see — including combat — to a text log file for the rest of the session.

2. Find the file

It's named eqlog_<YourCharacter>_<Server>.txt, inside your game install's Logs folder (for example ...\EverQuest\Logs\ or ...\EverQuest Legends\Logs\, depending on which client you run). If you're not sure, search your drive for eqlog_.

3. Live tracking (Chrome or Edge)

Open the Live tab and click Pick log file…, then select your eqlog_*.txt. Parselight re-reads only the new bytes appended since the last check, so it keeps up with the fight without re-scanning the whole file. Grant the file permission when the browser asks.

Other browsers

Firefox and Safari don't support live file watching from a web page. Use Choose file (one-time / manual refresh) instead — it reads the file once, and you can click it again whenever you want an update.

Analyzing a past session

Use the Analyze Log tab any time — drop in a saved eqlog_*.txt (or a copy of it) after the fact for a full breakdown, charts, and a CSV export. This works in every browser, since it's a one-shot read.

How this works & its limits

  • Everything runs locally in your browser. Your log never leaves your machine — there's no server involved.
  • This only reads the text your own client already writes to disk when logging is on. It doesn't read game memory, inject anything, or automate play, so it carries none of the risk a memory-reading tool would.
  • Your log only contains what your own client saw, so the meter reflects damage dealt near you — the same limitation every EverQuest parser has.
  • Damage-over-time ticks that don't name a caster ("A rat_snake has taken 12 points of non-melee damage.") can't always be attributed to a specific player. Turn on Solo mode when you're playing alone so those are credited to you; in a group they're shown as "Unattributed" rather than guessed.
  • Log message wording can vary slightly between EverQuest versions and servers. Anything that looks combat-related but isn't recognized shows up in the Debug panel so the pattern can be added.
Dyrelog reads your local EverQuest combat log only. Nothing is uploaded unless you log in and submit a fight yourself — and nothing ever touches the game process.

What leaves your machine

Logging in and submitting a fight is entirely opt-in — local DPS tracking above works the same with or without it.

  • Only the raw log lines for whichever fight is currently active get sent — never your whole log file, never chat, never anything from outside that one encounter.
  • They're sent gradually while the fight happens (not saved up and dumped at once) so the leaderboard can trust it was actually tracked live, not faked afterward.
  • Nothing publishes until you press Submit on that fight — streaming just stages it for review first.
  • The server re-reads those raw lines itself to compute the real numbers — it never just trusts a number this app sends.
