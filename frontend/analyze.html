Analyze a log

Where's my log? In EverQuest Legends, type /log on, then look in wherever you downloaded your game to find the game's Logs folder. It should be named something like: eqlog_YourName_pq.proj.txt.

Drop your EverQuest Legends log file below and Dyrelog breaks down every fight by combatant, damage, dps, hits, crits, procs, and even has a dps-over-time graph. The file is never uploaded anywhere, the same way the desktop overlay never sends your log anywhere either. This only touches the log file.
