Download the overlay

Dyrelog overlay is a free, always-on-top desktop app for EverQuest Legends. It runs entirely on your own machine, reads your combat log, and shows you a live dps meter while you play.

Download for Windows ↓

Downloads the installer straight from GitHub. The Windows installer isn't code-signed yet, since that costs money a small fan project doesn't have, so SmartScreen may warn you the first time you run it. That's expected, not a sign anything's wrong. It just costs money to get rid of that

What it looks like

A standard bar meter, a mini-mode for minimalists, and a circle for weirdos who like circles. Comes with a deep-dive analysis tool and a leaderboard system for fun.

Setup

  1. Click the download button above to grab the installer.
  2. Run it and follow the prompts. If Windows SmartScreen shows a warning, choose "More info" then "Run anyway".
  3. Launch Dyrelog and point it at your EverQuest Legends log file. You should only have to do this once, as it remembers the location from then on.
  4. Open Settings from the gear icon to pick a theme, adjust sizing, and set up leaderboard submission preferences.

System requirements

Windows is the actively supported platform right now. Mac and Linux builds exist but haven't been tested yet, so if you try one, a bug report on GitHub is very welcome.
