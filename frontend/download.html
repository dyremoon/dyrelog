Download the overlay

Dyrelog's overlay is a free, always-on-top desktop app for EverQuest Legends. It runs entirely on your own machine, reads your combat log, and shows you a live dps meter while you play.

Get the latest release ↗

Opens the GitHub releases page. The Windows installer isn't code-signed yet, since that costs money a small fan project doesn't have, so Windows SmartScreen may warn you the first time you run it. That's expected, not a sign anything's wrong.

What it looks like

A ranked bar list while you fight, a small circular badge if you'd rather it stay out of the way, and a separate Combat Analysis window when you want the full breakdown afterward.

Bars — the default live dps meter
Circle — a small always-on-top badge
Combat Analysis — the deeper breakdown

Setup

  1. Download the installer from the releases page above.
  2. Run it and follow the prompts. If Windows SmartScreen shows a warning, choose "More info" then "Run anyway".
  3. Launch Dyrelog and point it at your EverQuest Legends log file once — it remembers the location from then on.
  4. Open Settings from the gear icon to pick a theme, adjust sizing, and set up leaderboard submission.

System requirements

Windows is the actively supported platform right now. Mac and Linux builds exist but haven't been tested yet — if you try one, a bug report on GitHub is very welcome.
