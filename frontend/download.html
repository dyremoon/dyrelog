Download the overlay

Dyrelog overlay is a free, always-on-top desktop app for EverQuest Legends. It runs entirely on your own machine, reads your combat log, and shows you a live dps meter while you play.

Download for Windows ↓

This button records an aggregate download request by day and app version before redirecting to GitHub. No visitor ID or IP address is stored in download analytics. This is separate from optional in-app usage analytics.

If the download does not start, open GitHub Releases.

The installer comes straight from GitHub. It isn't code-signed yet (signing costs money a small fan project doesn't have), so Windows SmartScreen may warn you the first time you run it. That's expected. Choose "More info", then "Run anyway".

What it looks like

A standard bar meter, a mini-mode for minimalists, and a circle for weirdos who like circles. Comes with a deep-dive analysis tool and a leaderboard system for fun.

Setup

  1. Click the download button above to grab the installer.
  2. Run it and follow the prompts. If Windows SmartScreen shows a warning, choose "More info" then "Run anyway".
  3. In EverQuest, type /log on so the game writes a combat log.
  4. Launch Dyrelog and pick your EverQuest folder (or its Logs folder). Dyrelog finds your eqlog_<Character>_<Server>.txt file and remembers it.
  5. To put kills on the leaderboard, log in with Discord when the app asks (or later in Settings → Options). Only kills of known bosses can be submitted.
  6. Open Settings from the gear icon to pick a theme, adjust sizing, and change submission options.

Updates

Dyrelog checks for a new version about once an hour while it's open. When one is out, a banner appears at the top of the meter. Click it and Dyrelog downloads the update, installs it and restarts. You can also check any time in Settings → What's New.

Usage analytics is optional and off until you choose “Allow” in the app. If allowed, the packaged app sends a random installation ID, app version, and platform to Dyrelog’s Cloudflare-hosted service on startup and every 15 minutes while running; the server records observation dates. No account identity, game data, or personal files are sent by usage analytics. Records currently have no automatic expiry. Change your choice in Settings → Options → Usage analytics. Turning it off stops future reports, but does not erase records already received.

System requirements

Windows 10 or 11. Mac and Linux aren't supported yet.
