Download Dyrelog

Free DPS meter for EverQuest Legends. Windows 10 or 11.

Download for Windows ↓

Download not starting? Get Dyrelog-Setup-<version>.exe from GitHub Releases.

Install and set up

  1. Run the installer. Windows SmartScreen may warn you because the installer isn't code-signed (that costs money a small fan project doesn't have). Choose More info, then Run anyway.
  2. Open Dyrelog. It asks if you want to put your boss kills on the leaderboard. Say yes and sign in with Discord, or keep everything local. You can change this later in Settings.
  3. Pick your EverQuest Legends folder. Dyrelog finds your log file and remembers it.
  4. If you've never turned on logging, type /log on in game.

Updates

Once it's installed, you don't need to come back here. When a new version is out, a banner shows up at the top of the meter. Click it and Dyrelog updates itself and restarts.

Want to see it first? Check the About page. The download button counts downloads per version and nothing else; see Privacy for what the app sends.
